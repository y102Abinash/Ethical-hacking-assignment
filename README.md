# Ethical Hacking Assignment

This repository contains my **Ethical Hacking Assignment** as part of my cybersecurity coursework.  
The objective was to apply various reconnaissance and penetration testing techniques on `apple.com` to identify potential security vulnerabilities.  
The work was performed for **educational purposes only**.
